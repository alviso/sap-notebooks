# SAP notebooks

Interactive study pages over real SAP code. Each notebook takes real Z code, old and new, and anchors short notes
to the lines that matter. They are written for people who already know the basics, so the notes go after the
nuances.

Read them at **https://alviso.github.io/sap-notebooks/**

## Notebooks

| Notebook | What it covers |
|---|---|
| [RAP Port Notebook](https://alviso.github.io/sap-notebooks/rap-port-notebook/) | Two custom transactions ported from dynpro to RAP: ZCRED (credit limit change, one managed entity, additional save) and ZMM01 (retail article with variants, parent and child in a strict BDEF, save as a static action). 81 line-anchored notes, old rule to new home pairs, 16 drill questions. |

## How a notebook is built

Each notebook is one static HTML file with no server and no tracking. The only outside request is for the IBM Plex
fonts from Google Fonts. Your drill progress stays in your browser's local storage.

The page is generated by a small Python script (standard library only) that reads the source files, resolves each
note to a line number by searching for a line of code, and fails if a note no longer matches. To rebuild the RAP
Port Notebook you need a checkout of [alviso/proof-port](https://github.com/alviso/proof-port) next to this repo:

    git clone https://github.com/alviso/proof-port
    git clone https://github.com/alviso/sap-notebooks
    cd sap-notebooks/rap-port-notebook
    python3 build.py              # writes index.html

Set `PROOF_PORT=/path/to/proof-port` if the checkout is somewhere else.
